# React app (Vite, TypeScript)

A React app served by Vite. It starts by itself and the preview updates as soon as you save.

## Run it

Vite is already running in the `app` terminal tab. Edit a file and watch the preview change.
If the preview gets stuck, restart Vite: click the `app` tab, press Ctrl+C, then press ↑ and Enter.

## Files

- `src/App.tsx` is the main component, the place to start.
- `src/main.tsx` mounts the app into `index.html`.
- `src/App.css` and `src/index.css` hold the styles.
- `package.json` lists the packages. To add one, run `npm install <name>` in a new terminal.
